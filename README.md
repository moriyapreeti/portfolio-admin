# Portfolio Admin Panel (React + Vite + Tailwind)

Admin UI for the Portfolio CMS backend.

    npm install
    cp .env.example .env    # set VITE_API_URL if backend is not on http://localhost:8080
    npm run dev             # http://localhost:5173

Log in with the admin email/password configured in the backend.
To add a new content type, add one entry in `src/resources.js`.
